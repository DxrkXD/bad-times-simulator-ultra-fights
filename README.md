# Bad Time Simulator: Ultra Fights

A static GitHub Pages-style browser game inspired by Undertale's boss-fight rhythm and dodging combat.

## Features
- Fight against multiple Undertale-inspired bosses:
  - Ultra Sans
  - Papyrus
  - Gaster
  - Asgore
- Dodge bullets, bones, and arcs in a simple bad time simulator arena
- Combo of bullet hell patterns and soul movement
- Runs as a static website without any build tools

## Run locally
Open `index.html` directly in a browser, or serve it with a quick local web server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## GitHub Pages
To publish on GitHub Pages:
1. Push this repository to GitHub
2. Open the repository settings
3. Go to Pages
4. Set source to `Deploy from a branch`
5. Choose the `main` branch and `/ (root)` folder
6. Save

Your site should be live at:
`https://<your-username>.github.io/bad-times-simulator-ultra-fights/`

## Notes
This is an original browser game inspired by Undertale mechanics and visual tone. It uses custom, original artwork and logic rather than official assets.
